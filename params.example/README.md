# params.example — Required Per-Deployment Parameters

Copy this directory to `params/` (which is gitignored) and fill in real values.

`params/` is the single place for all secrets and personal configs that must
never be committed. The `.env` file at the repo root is the primary source
of truth for secrets; `params/` holds any additional credential files generated
during provisioning.

## Files in this directory

| File | Purpose | How to obtain |
|------|---------|---------------|
| `.env` | All deployment secrets (see `.env.example`) | Copy `.env.example` → `.env` and fill in |
| `talosconfig` | Admin talosconfig for the Talos cluster | Written by `deploy-local.sh` to `envs/<env>/generated/talosconfig` |
| `kubeconfig` | Admin kubeconfig for the cluster | Written by `deploy-local.sh` to `envs/<env>/generated/kubeconfig` |
| `mc-talos-prod-cp1.yaml` | Talos machine config (control plane 1) | Generated by `talosctl gen config` |
| `mc-talos-prod-cp2.yaml` | Talos machine config (control plane 2) | Generated by `talosctl gen config` |
| `mc-talos-prod-cp3.yaml` | Talos machine config (control plane 3) | Generated by `talosctl gen config` |
| `.public-deny` | Fail-closed deny-scan patterns for the public mirror (see `.public-deny.example`) | Copy `.public-deny.example` → `.public-deny` and add your real identifiers |
| `.public-genericize` | Real→placeholder rewrite map for the public mirror (see `.public-genericize.example`) | Copy `.public-genericize.example` → `.public-genericize`, paired 1:1 with `.public-deny` |

## Quick start

```bash
cp -r params.example params
cp .env.example params/.env
# Edit params/.env with real values
ln -sf params/.env .env          # optional: keep .env at repo root as a symlink
```

## Generated credential files

`deploy-local.sh` writes generated credentials to `envs/<env>/generated/` which is
already gitignored. After a successful deploy, copy them to `params/` as your
single safe backup location:

```bash
cp envs/productie/generated/kubeconfig params/kubeconfig
cp envs/productie/generated/talosconfig params/talosconfig
```

## Public-mirror sanitization

`scripts/sync-to-public.sh` (run by `.github/workflows/sync-to-public.yml`) publishes a
sanitized subset of this PRIVATE repo to the PUBLIC template mirror. Two gitignored maps
under `params/` drive the content sanitization on top of the structural strips
(`terraform/`, `ansible/`, `envs/`, `params/`, `private-apps/`, `overlays/*/prod`,
`users.yaml`, `*.tfvars/key/pem`):

| Map file | Role | CI secret (fail-closed) |
|----------|------|-------------------------|
| `params/.public-deny` | Fail-closed content deny-scan — any match ABORTS the sync | `PUBLIC_DENY_LIST` |
| `params/.public-genericize` | Real→placeholder rewrite applied to the export copy before the deny-scan | `PUBLIC_GENERICIZE_MAP` |

- CI materializes each map from its repo secret and **refuses to sync if the secret is
  unset**, so the deny-scan and genericize transform can never be silently skipped.
- Keep each secret and its local `.example`-derived map in sync, or a local
  `sync-to-public.sh` run will differ from CI.
- **Every real identifier belongs in BOTH maps AND BOTH secrets.** Cover, at minimum:
  real domain, GitHub owner/GHCR namespace, real usernames/handles (all case variants,
  including UPPERCASE env-var derivations), public/WAN IPs, Cloudflare zone/account IDs,
  RFC1918 subnets baked into base manifests, and real storage/export paths.

Set the secrets with:
```bash
gh secret set PUBLIC_DENY_LIST      < params/.public-deny
gh secret set PUBLIC_GENERICIZE_MAP < params/.public-genericize
```

## Secret rotation checklist

If any of the following may have been exposed, rotate them immediately:

- `PROXMOX_API_TOKEN` — Proxmox datacenter → Permissions → API Tokens
- `CF_API_TOKEN` — Cloudflare dashboard → My Profile → API Tokens  
- `DEPLOYER_SSH_KEY` — run `ssh-keygen -t ed25519` and re-provision nodes
- Talos CA key (`mc-talos-prod-*.yaml`) — run `talosctl rotate-ca` or rebuild cluster
- kubeconfig admin key — re-issue via `talosctl kubeconfig`

## History note

If secrets were ever accidentally committed to git history, run:
```bash
git log -p -- .env envs/productie/talosconfig talos/clusterconfig/talosconfig \
  | grep -E 'token|key|password|secret|BEGIN'
```
and rotate any credentials found before making the repo public.
